# HomeVZ App Icon Design Specification

## Design Concept
The HomeVZ app icon should represent a modern housing/real estate platform with Kenyan context.

## Design Elements
1. **Primary Shape**: Rounded square with slight corner radius
2. **Background**: Gradient from primary green (#2E7D32) to lighter green (#4CAF50)
3. **Main Icon**: Stylized house/building with modern design
4. **Accent**: Small Kenyan flag element or orange accent (#FF7043)
5. **Typography**: Clean, modern "HVZ" monogram

## Color Palette
- Primary Green: #2E7D32 (matches app theme)
- Secondary Green: #4CAF50
- Accent Orange: #FF7043
- White: #FFFFFF
- Dark Gray: #333333

## Icon Specifications
- Size: 1024x1024px (high resolution)
- Format: PNG with transparency
- Style: Flat design with subtle shadows
- Safe Area: 20% margin from edges
